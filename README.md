# Summer Camps Dashboard 2026

An interactive calendar dashboard for comparing and planning summer camps for kids.

## Features

- 📅 **Calendar View** - Visual month-by-month calendar showing camps on specific dates
- 📊 **Table View** - Sortable table with all camp details
- 📈 **Timeline View** - Chronological overview of all camps
- 💰 **Price Tracking** - See costs at a glance with total summary
- ⏰ **Time Display** - Half-day vs full-day indicators
- 📱 **Mobile Responsive** - Works on all devices

## How to Update

To add or modify camps, edit the `camps` array in `index.html` starting at line ~500.
